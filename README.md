# 🏗️ Construction Requisition System

A comprehensive project expense management system for construction companies.

## 🚀 Live Demo

[View Live App](https://your-app-name.streamlit.app)

## ✨ Features

- Project Management
- Requisition Processing with Multi-level Approval
- Contractor Management
- Financial Reports with PDF/Excel Export
- Role-based Access Control (Admin, CEO, Verifier, Data Entry)
- Balance Sheet Management
- Transaction Tracking by Category
